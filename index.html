Two-Step Login with TOTP

Normally you log in with a password. With two-step login you also type a 6-digit code from your phone. The code changes every 30 seconds, so a stolen password alone is not enough to get in.

How it works

  1. The website gives your phone a secret, once, using a QR code.
  2. Your phone mixes the secret with the current time to make a 6-digit code.
  3. You type the code in. The website does the same maths, and if the codes match, you are in.

Code not working?

  • Spaces are fine: "123 456" and "123456" both work.
  • Set your phone's date and time to automatic. A wrong clock is the most common cause, and this page will tell you if your clock looks wrong.
  • If you made more than one secret, delete the old entries in your app and use the newest.
  • If the buttons do nothing, open the page with Live Server in VS Code (or from https://), not from a plain network address.
